## Description (full)
Duck Epics turns any Trello card into a **Subscription** (an epic / client) with **Sub-tasks** —
a parent → child hierarchy that Trello doesn't have out of the box.

**What you get**
- Mark a card as a Subscription and give it an icon.
- Create new sub-tasks, or attach existing cards as sub-tasks (add several at once).
- A live progress bar and an X/Y done badge on the Subscription card.
- Rich sub-task rows: status column (change via dropdown or drag), due date with
  overdue/soon highlighting, checklist progress, assignees, and a one-click "done" toggle.
- Edit a sub-task's due date, assignees and a custom link right from the row.
- Add a link to the Subscription itself (e.g. the client's site) — also written to the card's
  description.
- Collapse/expand columns, sort newest-first, filter the attach list by column.
- Archived sub-tasks are grouped separately with Open / Unarchive actions.
- Instant, optimistic updates; no external server — all data stays inside Trello.

**Great for** agencies and teams managing clients/epics with many underlying tasks.
